# Icon sets in the icon picker

Which of Iconify's 238 icon sets the icon-question picker searches, and why each
one is in or out. The allowlist itself is in [iconSets.js](./iconSets.js). Last
checked on 2026-10-04.

Picked icons are uploaded and served as survey resources, so Qlarr redistributes
them and each set's license applies to Qlarr.

## Summary

| Status | Sets | Icons |
|---|---|---|
| ✅ In, no credit needed | 102 | 225,957 |
| ✅ In, credit required (CC BY 4.0, 17 credit lines) | 41 | 50,390 |
| ❌ Out | 95 | 103,260 |
| **Total** | **238** | **379,607** |

## How to read the table

- **License (rows 1–168)** was checked against the set's own repo, npm package
  or Figma Community page, not Iconify's metadata. Iconify's label was wrong
  for css.gg, Unicons, Reicon, Firefox OS Emoji and Bitcoin Icons.
- **License (rows 169–238)** is Iconify's label, not verified. These sets are
  out for another reason (hidden, font license, brand logos, archived), so
  check their licenses before adding any of them.
- **✅ In (credit)** sets are free for commercial use, but CC BY requires a
  credit line (set name, author, link, license) somewhere users can find it.
  The app does not show these credits yet. Build them from
  `CREDITED_ICON_SETS` in [iconSets.js](./iconSets.js). Streamline's license
  asks for the credit to link to streamlinehq.com.
