# File Upload Limits

This page lists the largest file you can upload in each part of Qlarr.

## Files respondents upload in a survey

| Question type | Maximum file size |
|---|---|
| Video capture | 60 MB |
| Photo capture | 10 MB |
| File upload | 10 MB |
| Signature | No limit |

When you design a survey, you can set a lower limit on any photo, video or file upload question. Respondents then see your limit instead of the default one.

## Files you upload when building and managing surveys

| What you upload | Maximum file size |
|---|---|
| Survey import file | 100 MB |
| Images and videos you add to a survey | 100 MB |
| Autocomplete list | 100 MB |
| Translations file | 5 MB |
| Images inserted into question text | 10 MB |

**Images and videos you add to a survey** are optimized automatically after you upload them. This keeps surveys fast to load for respondents, especially on mobile.

**Survey import files** can contain at most 500 files, and their total size once unpacked must stay under 500 MB.

## If a file is too large

The upload is rejected and you see an error message. To fix it, reduce the file before uploading again:

- **Videos:** record a shorter clip or use a lower resolution.
- **Photos and images:** resize them or save them in a compressed format such as JPEG.
